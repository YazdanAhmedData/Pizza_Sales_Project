# Pizza Sales Analysis | SQL & Tableau

An end-to-end sales analytics project exploring pizza-store performance with SQL and Tableau. The goal is to turn transactional sales data into business-facing reporting that helps stakeholders understand sales trends, product mix, order patterns, and areas worth investigating.

## Business Questions

- How do sales and order activity change over time?
- Which pizza categories, sizes, and products contribute most to sales?
- Which products are top and bottom performers?
- What patterns could inform menu planning, inventory decisions, and promotions?

## Tools

- **SQL** — querying, aggregation, KPI calculations, and business-question analysis
- **Tableau** — interactive dashboarding and visual exploration
- **CSV** — source sales data

## Analysis Approach

1. Review the dataset and identify fields required for sales and order analysis.
2. Use SQL to aggregate sales and answer the project’s business questions.
3. Compare performance by time period, category, size, and product.
4. Present the analysis in Tableau so the results can be explored visually.

## KPIs to Review

The project is structured around sales performance measures such as total revenue, order volume, average order value, quantity sold, and product/category contribution. Refer to the SQL queries and dashboard for the calculations and results; values are intentionally not reproduced here without independently validating them.

## Business Value

This project demonstrates how transaction-level data can be converted into structured reporting for sales monitoring. The findings can support further investigation into product mix, demand patterns, menu performance, and inventory planning. Recommendations should be based on the measured results in the workbook rather than assumed from the chart titles alone.
