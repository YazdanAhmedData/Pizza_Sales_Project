# 🍕 Pizza Sales Analysis — SQL & Tableau

A complete data analytics project focused on analyzing pizza sales using **SQL and Tableau**.

The project combines SQL-based business analysis with interactive Tableau reporting to identify sales trends, product performance, customer ordering patterns, and key business KPIs.

## 🎯 Project Objective

The objective of this project is to analyze pizza sales data and answer important business questions using SQL while presenting the results through an interactive Tableau dashboard.

The project demonstrates an end-to-end analytics workflow:

```text
Raw Sales Data
      ↓
Data Preparation
      ↓
SQL Analysis
      ↓
Business Questions
      ↓
KPIs & Insights
      ↓
Tableau Dashboard
```

## 📂 Dataset

The primary dataset is:

```text
pizza_sales.csv
```

The dataset contains information related to pizza orders and sales.

## 🗄️ SQL Analysis

The project includes a SQL reporting file:

```text
PIZZA_QUERIES.sql
```

The SQL analysis is designed to answer business questions related to pizza sales performance.

Examples of analytical areas include:

- Total revenue
- Total orders
- Total pizzas sold
- Average order value
- Average pizzas per order
- Daily order trends
- Monthly sales trends
- Pizza category performance
- Pizza size performance
- Top-selling pizzas
- Bottom-performing pizzas

## 📊 Tableau Dashboard

## 🔍 Business Analysis

### Sales Trend Analysis

Understanding daily and monthly sales patterns helps identify periods of high and low demand.

### Product Analysis

Pizza-level analysis helps identify products that contribute most significantly to sales.

### Category Analysis

Different pizza categories can be compared to understand their contribution to overall sales.

### Size Analysis

Pizza sizes can be analyzed to understand customer purchasing preferences.

### Top & Bottom Products

Identifying the best and worst-performing products can support decisions related to:

- Product promotion
- Menu optimization
- Inventory planning
- Marketing strategy
